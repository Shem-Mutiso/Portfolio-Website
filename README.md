# Personal Portfolio Website

A simple personal portfolio website built with HTML and CSS.

## What it does
Presents an about section, skills list, project highlights, and contact info in a clean, single-page layout.

## Concepts used
- Semantic HTML structure
- CSS styling (layout, color, spacing)
- Responsive-friendly design basics

## How to view
Open `index.html` in any web browser. No installation needed.

## How to publish (optional)
Upload to a GitHub repository and enable **GitHub Pages** (Settings → Pages) to get a live link.
